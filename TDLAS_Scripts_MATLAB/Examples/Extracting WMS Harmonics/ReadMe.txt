This example demonstrates how to align intensity signals to extract 
background subtracted WMS harmonics.

The folder "Sample Data" contains experimental scanned-WMS data, 
-before the signals were aligned "raw_data.mat" and 
- after "aglined_data.mat". 

The script "align_bg_signal.m" creates the file "aglined_data.mat".

Main script: "plot_WMS_Harmonics_LPF.m"
